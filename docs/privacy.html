隱私權政策 Privacy Policy

最後更新 Last updated: 2026-11-09

1. 這個工具是什麼 What this app is

social-uploader（以下稱「本工具」）完全在使用者自己的電腦上執行。開發者不經營任何伺服器，也不會收到使用者的任何資料。

social-uploader ("the app") runs entirely on the user's own computer. The developer operates no server and receives no user data.

2. 存取哪些資料 Data accessed

  • Google / YouTube：經使用者授權後，使用 YouTube Data API 上傳使用者選擇的影片，並讀取頻道名稱以確認連結的是哪個頻道。
    With the user's authorization, the app uses the YouTube Data API to upload videos the user selects, and reads the channel name to confirm which channel is connected.
  • Instagram：使用者提供的存取權杖，用來發佈 Reels 和讀取帳號名稱。
    The access token the user provides is used to publish Reels and read the account username.
  • TikTok：經使用者授權後發佈影片。
    With the user's authorization, the app posts videos.

3. 資料存放 Storage

所有授權權杖、設定與影片檔都只存放在使用者電腦上的本工具資料夾（data/）中，不會傳送給開發者或任何第三方。資料只會直接傳給使用者選擇發佈的平台（Google/YouTube、Meta/Instagram、TikTok）。

All tokens, settings and video files are stored only in the app's folder (data/) on the user's computer. Nothing is sent to the developer or any third party. Data is sent only directly to the platforms the user chooses to publish to (Google/YouTube, Meta/Instagram, TikTok).

4. 不分享、不販售 No sharing or selling

本工具不會分享、販售或用於廣告任何使用者資料。

The app does not share, sell, or use any user data for advertising.

5. 刪除資料與撤銷授權 Deletion and revoking access

刪除本工具的 data/ 資料夾即可清除所有本機資料。也可隨時在以下位置撤銷授權：

Delete the app's data/ folder to erase all local data. Access can also be revoked at any time:

  • Google: myaccount.google.com/permissions
  • Instagram: 設定 → 網站權限 → 應用程式和網站 / Settings → Website permissions → Apps and websites
  • TikTok: 設定與隱私 → 安全性 → 管理應用程式權限 / Settings and privacy → Security → Manage app permissions

6. YouTube API 服務 YouTube API Services

本工具使用 YouTube API 服務。使用本工具即表示同意 YouTube 服務條款，並適用 Google 隱私權政策。

The app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.
