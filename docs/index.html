social-uploader

個人自用的多平台影片上傳工具 · A personal multi-platform video uploader

social-uploader 是一個在使用者自己電腦上執行的工具，讓使用者選一次影片，就能透過各平台的官方 API，立即或排程發佈到自己的 YouTube、Instagram 與 TikTok 帳號。

social-uploader is a tool that runs locally on the user's own computer. It lets the user publish a video to their own YouTube, Instagram and TikTok accounts, immediately or on a schedule, using each platform's official API.

功能 Features

  • 透過 YouTube Data API 上傳影片到使用者自己的頻道 / Upload videos to the user's own channel via the YouTube Data API
  • 透過 Instagram API 發佈 Reels / Publish Reels via the Instagram API
  • 透過 TikTok Content Posting API 發佈影片 / Post videos via the TikTok Content Posting API
  • 各平台分別設定說明文字、hashtag 與發佈時間 / Per-platform captions, hashtags and schedule
